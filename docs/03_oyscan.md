# 03. Oyscan — 海を診る

PC 向け。地図（地理院タイル）で日本の海をクリックすると、気象庁の沿岸海域の海面水温と最寄り観測所の雨量をルールで判定し、Claude が所見を書く。**判定は水温と雨量だけ**。診断できる海域は気象庁の沿岸海域のうち本土沿岸 80 区分（11/3 に周防灘 1 つから拡大）。

## 画面

左：地図（MapLibre GL JS ＋ 地理院タイル）。初期表示は周防灘（中心 33.62N, 131.25E、ズーム 10 程度）。クリックでピンが立ち、「選択中：北緯○○ 東経○○（周防灘）」。周防灘の外をクリックしたら「この海域はまだ対応していません（対応海域：周防灘）」。
右：診断パネル。
1. 指標タイル3つ：**高水温リスク**（低／中／高）、**低水温期間**（年間○日）、**成長しやすい期間**（年間○日）
2. 直近の水温：直近7日の平均と、過去5年の同時期との比較（「平年値」は周防灘にないので使わない。5年統計の平均・最高・最低を使う）
3. 所見（Claude が生成。4〜6文）
4. 注意書き（固定文）
5. ボタン：**[AI Oysterman に引き継いで相談する]**（1つだけ。リブルへの相談ボタンは置かない）

## データ

- 日別：`https://www.data.jma.go.jp/kaiyou/data/db/kaikyo/series/engan/txt/area623.txt`（CSV、ヘッダ `yyyy,mm,dd,areaNo.,flag,Temp.`、2016-01-01〜、flag P=速報 R=再解析、欠損 -9999）
- 5年統計（平均・最高・最低。平年値列は周防灘では欠損）：同ディレクトリの統計ファイル。`scripts/fetch_jma.ts` で取得時にファイル名を確認して固定する（解説ページ：https://ds.data.jma.go.jp/kaiyou/data/db/kaikyo/series/engan/eg_info.html ）
- 取得は**ビルド時／デプロイ時に1回**（`scripts/fetch_jma.ts` → `apps/api/data/suonada.json`）。実行時に気象庁へリクエストしない。日次更新は不要（デモ用）。
- 海域番号表：https://ds.data.jma.go.jp/kaiyou/data/db/kaikyo/series/engan/eg_areano.html （623 = 周防灘）

## 全国版（11/3 更新）

- **データ**：`scripts/fetch_scan_areas.ts` がビルド時に、気象庁「日本沿岸域の海面水温情報」の全海域（公開のある 98 区分）の日別と 5 年統計、気象庁「過去の気象データ」気象官署 33 か所の日降水量（5 年分）を取り込み、海域ごとの指標を計算して `apps/api/data/scan_areas.json` に書く。実行時は気象庁へアクセスしない。取得結果は `.cache/jma/`（gitignore）にキャッシュ。
- **地図**：初期表示は日本全体（中心 37.0N 137.5E、ズーム 4.4）。本土沿岸 80 海域の中心点を斃死リスクの色で点表示。クリック地点から 150km 以内で最も近い中心点の海域を選ぶ（簡易判定。海域名を必ず表示）。離島・千島は点を置かない。
- **雨量**：各海域に最寄り 2 観測所の距離加重平均を割り当てる（観測所 1 つの偏りを減らす）。
- **指標**（閾値は `config/rules.yaml` の `oyscan`。2026-11-03 高畑確定）
  - 斃死リスク 低／中／高：28℃以上の日数（年平均。10 日以下＝0 点、40 日以下＝1 点、超＝2 点）と、6〜10 月の 50mm 以上の日数（年平均。3 日以下＝0、6 日以下＝1、超＝2）の合計。0〜1 点＝低、2 点＝中、3〜4 点＝高。
  - 成長スピード 良／普／鈍：15〜25℃の日数（年平均）200 日以上＝良、120 日以下＝鈍、間＝普。10℃未満が 90 日以上なら 1 段下げる。
  - 年間雨量（mm）と 50mm 以上の日数、直近 7 日平均と 5 年統計の同日との差、季節区分。
  - 全国分布（2021〜2025）：斃死リスク 低 36／中 22／高 22、成長スピード 鈍 23／普 27／良 30。周防灘は 中×普（28℃以上 34 日・大雨 5.7 日・15〜25℃ 140 日）。
- **所見**：`prompts/oyscan_report.md`。斃死リスクと根拠の数字 → 成長スピード → 3 倍体との相性 → 現地確認 → 貝毒は県へ、の順で 4〜6 文。
- **旧仕様**（周防灘のみ・高水温リスク 3 段階）は 11/2 の実装メモとして下に残す。

## 実装メモ（11/2 追記・旧仕様）

- 周防灘の内外判定は簡易矩形：北緯 33.5〜34.1、東経 130.9〜131.9（`apps/api/src/scan.ts`）。縁（関門側・伊予灘側）は粗い。
- 地図は MapLibre GL JS ＋ 地理院タイル「淡色地図」（`https://cyberjapandata.gsi.go.jp/xyz/pale/{z}/{x}/{y}.png`）。初期表示は中心 33.62N 131.25E、ズーム 9.5、ピンなし。
- 集計は「データ最終日の年を除く直近 5 年（完全な年）」。2026-11 時点は 2021〜2025。
- 画面はクリック直後に指標 3 つと直近水温を出し（`/api/scan/evaluate`、即時）、所見（`/api/scan/report`、数秒）はあとから同じパネルに追記する 2 段階。所見の保存 ID で `/oysterman?from=scan&report=<id>` に引き継ぐ。
- 所見はサーバーで禁止表現（必ず／安全です／最適です／予測・予報／死にます）と実在名を検査し、1 回だけ書き直させる。

## 判定ルール（`config/rules.yaml` の `oyscan` セクションを使う）

直近5年（データのある範囲）で集計：
- **高水温リスク**：28℃以上が7日以上続いた期間が、5年中何年あったか → 0年＝低、1〜2年＝中、3年以上＝高。あわせて最長連続日数を表示
- **低水温期間**：10℃未満だった日数の年平均 → 「生育が鈍る期間：年間約○日」
- **成長しやすい期間**：15〜25℃だった日数の年平均 → 「成長しやすい期間：年間約○日」
- **直近**：直近7日の平均、5年統計の同日の平均・最高・最低との差

## 所見の生成（`prompts/oyscan_report.md`）

Claude には集計済みの数値だけを渡し、4〜6文で書かせる。含めること：
- この海域の水温の特徴（成長期の長さ、高水温のリスクの有無）
- 3倍体シングルシードとの相性で**水温から言えることだけ**（例：夏の高水温期に作業時間を短くする運用が要る）
- 始める前に現地で確認すべきこと（塩分・流れ・水深は「要現地測定」）
- 「安全に出荷できるか（貝毒・衛生）は県に要確認」
含めないこと：漁具・種苗系統の推奨、想定生育%、予報めいた言い方、実在漁場名。

## 固定の注意書き（画面下とレポート末尾）

> 出典：気象庁「日本沿岸域の海面水温情報」（海域 623 周防灘）を加工して株式会社リブル作成。水温は海域全体の平均値（実績値）で、湾奥の個別地点とは異なります。予報ではありません。
> 地図：国土地理院 地理院タイル。
> 本診断は水温のみに基づく参考情報です。出荷の安全（貝毒・衛生基準）は都道府県の検査結果でご確認ください。

## 機能要件

| ID | 要件 | 優先 |
|---|---|---|
| OS-01 | 地図表示、クリックでピン、座標表示、周防灘の内外判定（簡易矩形で可） | Must |
| OS-02 | `apps/api/data/suonada.json` から指標3つと直近値を計算（`/api/scan/evaluate`） | Must |
| OS-03 | Claude が所見を生成（`/api/scan/report`） | Must |
| OS-04 | 診断結果を `scan_reports` に保存し、`/oysterman?from=scan&report=<id>` へ遷移 | Should |
| OS-05 | 出典・注意書きの固定表示 | Must |
| OS-06 | 実在漁場の座標をデフォルトにしない。ピンを立てない状態で開く | Must |

## 完成の定義

- クリック→3秒以内に指標3つと所見が出る
- 周防灘の外をクリックすると非対応表示
- 出典が画面にある

## 縮退案（11/5 夜までに間に合わない場合）

地図を静止画（地理院タイルのスクリーンショット＋出典）にし、「診断する」ボタン1つで固定ポイントの結果を出す。集計は `scripts/` でオフライン計算した JSON を返すだけにする。所見生成は残す。
