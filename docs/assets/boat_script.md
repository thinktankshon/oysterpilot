# 船上で言う文（印刷用・11/5 更新）

## 港で（乾いた手）

「作業開始」を押す。「作業中 0:00・記録 0 件」になったらホルダーに固定して出港。押すのはこの 1 回だけ。海では画面に触らない。

## 船上で（画面には触らない）

数字の前後で少し区切る。「K3」は「ケー、サン」。「D漁場」の D ははっきり。合図語のあとは 1 秒おく。言い間違えたら止めずに、もう一度最初から同じ文を言う（陸で直せる）。

1. **R8のK3、陸揚げ。D漁場 5レーン 5間目から12間目、10かご、選別のため**
2. **次のロット**
3. **R8のK3、沖出し。40かご、D漁場 5レーン 1間目から8間目へ**
4. **記録終了**

iPhone 下部のマイクを手で覆わない。風上を向かない。

## 岸に戻ってから（選別台）

5. **R8のK3、選別。30グラム60個入り10かご 15リットル、40グラム50個入り30かご 25リットル。死んだのは12個。刃先が伸びてる。付着物あり**

## ナレーション要旨（あとで録音）

港で 1 回押せば、あとは海で喋るだけ。確認は陸で。Claude が作業・ロット・場所・サイズ・斃死を整理して、足りないことは聞き返す。
