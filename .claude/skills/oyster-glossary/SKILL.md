# oyster-glossary — 用語と言い回しのルール

このスキルは「言葉」の決まりだけを扱う。数字の閾値は `config/rules.yaml`、用語の定義は `config/glossary.yaml` が正本で、ここに書いてある内容と食い違ったら正本に従い、このファイルを直す。

## 1. 使う用語（この言い方に揃える）

| 使う | 使わない | 意味 |
|---|---|---|
| 分殖（ぶんしょく） | かご分け、カゴ分け | 1 かごの数を減らし、かごを増やすこと |
| 選別 | サイズ分け、ふるい（会話で出たら選別に正規化） | 陸に揚げた貝をサイズで分け、かごに入れ直す作業 |
| 入数（いりすう） | 密度、個数 | 1 かごに入れる貝の数 |
| 沖出し場所 | 漁場、ポイント | かごを吊ったライン番号と段（例：3番ライン・上段） |
| 上段／中段／下段 | 上／下 | ラインの段。上段は揺れ強・干出長・成長遅、下段は成長早 |
| 斃死（へいし） | 死亡、死滅 | 死んだ貝。「死にます」とは言わない |
| 刃先（はさき） | 新生殻、成長縁 | 殻の縁の、新しく伸びた薄い部分（現場語。公的定義なし） |
| 揺れ | 波、動き | 波や潮でかごの中の貝が動くこと。刃先が削られて殻が丸く深くなる |
| 身入り／身質 | 太り、肉 | 身の詰まり具合 |
| 一潮（ひとしお） | 2 週間 | 大潮から次の大潮まで、約 2 週間。選別の目安は 2 潮＝約 30 日 |
| 3 倍体 | 三倍体（表記ゆれ可）、不稔 | 「ほとんど産卵しない」。「産卵しない」と言い切らない |
| シングルシード | 一粒かき（併記可） | 貝を 1 粒ずつばらして、かごで育てる養殖方法 |
| ロット R8-K3 | ロット 3、L-03 | R は令和の年度、K は採苗回数。選別で分けても番号は変わらない |
| サイズ選別／重量選別 | — | 20g までは殻の大きさ（10mm 刻み、〜40mm）、20g 以上は重さ（10g 刻み） |
| 作業セッション／区切り | 録音、セグメント | Voysy の「作業開始」から「記録終了」まで／合図語で分けた 1 つの発話 |
| 陸でチェック | 確認画面、レビュー | 区切りを陸で整理・保存する画面 |

## 2. 言い回しのルール（全画面・全プロンプト共通）

- **断定しない**。「死にます」「必ず」「予測」「安全です」「最適です」は使わない。高水温は「斃死が増えやすい時期です」まで。将来の値は言わない（予報ではない）。
- **斃死の原因を断定しない**。「原因は一つに決めず、密度・水温・雨量・場所・時期・青潮や赤潮の順に見てみましょう」の形。
- **目安であって厳守ではない**。数字を言うときは「目安です」「厳守ではありません」を添える。
- **出どころを言う**。ルール表の数字は「目安」、現場の話は「リブルの現場では」、文献は「〜と報告されている」「県の試験では」。URL・文献番号・社名は言わない。
- **場所を必ず言う**。記録の数字を引くときは「3番ライン・上段の記録では」と場所を付ける。
- **範囲外は専門家へ**。病気・衛生・貝毒・生食用の可否・販売・価格・漁業権・補助金・保険・法規・薬は判断せず、「先輩に聞く項目として整理します」と言い、確認先の種類（県の水産担当課、保健所、漁協、水産試験場）だけ言う。
- **伴走者の口調**。隣で教えてくれる先輩。短く、具体的に、理由を一言。質問は 1 つだけ。

## 3. 書いてはいけないもの（リポジトリ全体）

- 実在の漁場名・地点名（中津②、那佐、浅川 など）、既存システム名（Oysmart）、実績データの数字。
- API キー、`.dev.vars` の中身、共有パスワード。
- 「海がきれいになる」（瀬戸内は貧栄養が課題なので使わない）。

## 4. 画面の文言

- 日本語、文字 18px 以上、ボタンは高さ 56px 以上。
- 出典表示：気象庁の水温・雨量と地理院タイルを使う画面には固定の注意書き（docs/03）。
- Oyscan の指標の近くには「公開データを参考にした推察値。同じ海域でも潮流や潮の当たり方、水深、場所で変わる」の注釈。

## 5. 迷ったら

用語の定義が `config/glossary.yaml` に無い、または解釈に迷うときは、推測で補わずユーザー（高畑）に確認する（CLAUDE.md Rule 2）。
